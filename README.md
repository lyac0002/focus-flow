# Focus Flow

Focus Flow is a single-page task management web application built with HTML, CSS, and Vanilla JavaScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Filter tasks by All, Active, and Completed
- Sort tasks by due date or priority
- 25-minute Pomodoro focus timer
- 5-minute break timer
- Local Storage
- Input validation
- Responsive design

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript
- Local Storage
- GitHub Pages

## Live Demo

https://lyac0002.github.io/focus-flow/

## How to Use

1. Enter a task name.
2. Select a due date and priority.
3. Click Add Task.
4. Use the Complete, Edit, or Delete buttons to manage tasks.
5. Use the filters to view All, Active, or Completed tasks.
6. Sort tasks by due date or priority.
7. Use the Focus Timer for a 25-minute work session or a 5-minute break.
